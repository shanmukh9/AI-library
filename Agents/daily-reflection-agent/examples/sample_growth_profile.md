# Sample Growth Profile

This sanitized file is safe to use for a public demo. Copy it into `knowledge/` before building the RAG indexes.

## AI Career

The user wants to become a consistent AI builder rather than only consuming tutorials, podcasts, and courses. Small visible outputs matter: a script, a commit, a README improvement, or a short demo.

## Fitness and Energy

The user is building a simple movement routine with walking, mobility, and basic strength work. Recovery and sleep should support focused work rather than becoming another complicated tracking project.

## Discipline

The user benefits from small promises that are easy to start and easy to verify. When the plan feels large, reduce it to one action under ten minutes.

## Communication

The user wants to practice clearer written and spoken expression through small repeated reps. Sharing one learning or asking one thoughtful question is useful progress.

## Recurring Pattern

Passive learning can feel productive while delaying visible output. A useful rule is: create one tiny artifact before consuming more educational content.
